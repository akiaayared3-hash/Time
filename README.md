# Time - Burger & Pizza Delivery Platform

A full-stack food delivery website for burgers and pizza.  
Includes a customer-facing store, admin dashboard, and backend API.

> Project Status: **In Progress**

## Features

### Customer Side
- Browse burgers and pizza
- Add items to cart
- Place orders
- User authentication (Register / Login)
- Order tracking

### Admin Dashboard
- Manage products (Add, Edit, Delete)
- View and manage orders
- Manage categories
- Upload product images

### Backend
- RESTful API
- JWT Authentication
- Secure password hashing
- Image upload support
- MySQL database

## Tech Stack
